# 4.2.4. State Transition Testing

> **Casca.** Este arquivo não contém o texto do syllabus. O resumo é nosso (não é texto do ISTQB).
> Para o conteúdo exato, veja a seção e a página indicadas no PDF oficial ou o arquivo em `syllabus-texto/`.

## Resumo (nosso)

Modela estados, eventos, condições de guarda e ações (diagrama ou tabela de estados, que mostra também as transições inválidas). Critérios: todos os estados; transições válidas (0-switch, o mais usado); e todas as transições (válidas e inválidas, uma inválida por caso para evitar mascaramento). Todas as transições é o mínimo para software crítico.
