# 4.2.2. Boundary Value Analysis

## Resumo (nosso)

Só vale para partições ordenadas e testa os limites, onde os desenvolvedores mais erram. Na BVA de 2 valores, cada limite gera dois itens (o limite e o vizinho da partição adjacente); na de 3 valores, três (o limite e os dois vizinhos). A de 3 valores é mais rigorosa e pega defeitos que a de 2 valores deixa passar.
