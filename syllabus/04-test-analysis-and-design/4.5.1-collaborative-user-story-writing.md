# 4.5.1. Collaborative User Story Writing

> **Casca.** Este arquivo não contém o texto do syllabus. O resumo é nosso (não é texto do ISTQB).

## Resumo (nosso)

User story = Card, Conversation e Confirmation (critérios de aceite), no formato "Como [papel], quero [objetivo], para [valor]". É escrita em conjunto pelas perspectivas de negócio, desenvolvimento e teste. Boas stories seguem INVEST. Se ninguém sabe como testá-la, provavelmente está mal definida.
