# 4.3.3. The Value of White-box Testing

## Summary (ours)

It takes the whole implementation into account, even with a vague specification, and gives an objective code coverage measure that black-box testing cannot. It also works in static testing (dry runs). It cannot detect defects of omission, i.e. requirements that were never implemented.
