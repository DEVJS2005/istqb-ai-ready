# 3.1.3. Differences between Static Testing and Dynamic Testing

> **Shell.** This file does not contain the syllabus text. The summary is ours (not ISTQB text).
> For the exact content, see the section and page given below in the official PDF, or the file in `syllabus-text/`.

## Summary (ours)

Static testing finds defects directly, reaches rarely executed paths, works on non-executable products and measures qualities such as maintainability. Dynamic testing provokes failures and measures things like performance. Static is cheaper for defects in requirements, design, code, standards, interfaces, some security weaknesses and coverage gaps.
