# 3.1.3. Differences between Static Testing and Dynamic Testing

> **Casca.** Este arquivo não contém o texto do syllabus. O resumo é nosso (não é texto do ISTQB).
> Para o conteúdo exato, veja a seção e a página indicadas no PDF oficial ou o arquivo em `syllabus-texto/`.

## Resumo (nosso)

O estático acha defeitos diretamente, alcança caminhos pouco executados, vale para produtos não executáveis e mede características como manutenibilidade. O dinâmico provoca falhas e mede, por exemplo, desempenho. O estático é mais barato para defeitos de requisitos, design, código, padrões, interfaces, algumas vulnerabilidades e lacunas de cobertura.
