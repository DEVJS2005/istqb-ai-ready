# 3.1.2. Value of Static Testing

## Resumo (nosso)

Encontra defeitos nas fases mais iniciais e alguns que o teste dinâmico não alcança (código inalcançável, defeitos em documentos). Cria entendimento comum entre stakeholders e, apesar do custo, reduz o custo total do projeto.
