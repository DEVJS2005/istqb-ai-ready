# 2.1.3. Testing as a Driver for Software Development

## Summary (ours)

TDD steers coding with test cases plus refactoring; ATDD derives tests from acceptance criteria before building; BDD describes behaviour in plain language (Given/When/Then) that becomes executable tests. All apply early testing and shift left.
