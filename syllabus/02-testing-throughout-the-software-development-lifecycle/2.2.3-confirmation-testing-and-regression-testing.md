# 2.2.3. Confirmation Testing and Regression Testing

> **Shell.** This file does not contain the syllabus text. The summary is ours (not ISTQB text).
> For the exact content, see the section and page given below in the official PDF, or the file in `syllabus-text/`.

## Summary (ours)

Confirmation re-runs the tests that failed or adds new ones for the fix. Regression looks for side effects in the component, the system or connected systems, guided by impact analysis. Regression suites grow with every delivery and are prime candidates for automation, including in CI.
