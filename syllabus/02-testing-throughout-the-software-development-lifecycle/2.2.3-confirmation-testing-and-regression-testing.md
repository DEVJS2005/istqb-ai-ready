# 2.2.3. Confirmation Testing and Regression Testing

> **Casca.** Este arquivo não contém o texto do syllabus. O resumo é nosso (não é texto do ISTQB).
> Para o conteúdo exato, veja a seção e a página indicadas no PDF oficial ou o arquivo em `syllabus-texto/`.

## Resumo (nosso)

A confirmação reexecuta os testes que falharam ou cria novos para a correção. A regressão verifica efeitos colaterais no componente, no sistema ou em sistemas conectados, guiada por análise de impacto. Suítes de regressão crescem a cada entrega e são fortes candidatas à automação, inclusive em CI.
