# 2.2.1. Test Levels

## Summary (ours)

Component (unit) testing isolates parts; component integration testing checks the interfaces between them; system testing looks at the whole, functional and non-functional; system integration testing covers external interfaces; acceptance testing validates readiness for use (UAT, operational, contractual, regulatory, alpha, beta). Levels differ by object, objectives, basis, defects and who is responsible.
