# 2.2.1. Test Levels

> **Casca.** Este arquivo não contém o texto do syllabus. O resumo é nosso (não é texto do ISTQB).

## Resumo (nosso)

Teste de componente (unidade) isola partes; o de integração de componentes testa interfaces entre elas; o de sistema avalia o todo, funcional e não funcional; o de integração de sistemas cobre interfaces externas; e o de aceite valida a prontidão para uso (UAT, operacional, contratual, regulatório, alfa, beta). Os níveis se distinguem por objeto, objetivos, base, defeitos e responsáveis.
