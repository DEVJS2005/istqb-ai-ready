# 2.2.2. Test Types

## Resumo (nosso)

Funcional cobre "o que" o sistema faz; não funcional cobre "quão bem", segundo as características da ISO/IEC 25010 (desempenho, compatibilidade, usabilidade, confiabilidade, segurança, manutenibilidade, portabilidade, safety). Caixa-preta deriva testes da especificação e caixa-branca, da estrutura interna. Todos se aplicam a todos os níveis.
