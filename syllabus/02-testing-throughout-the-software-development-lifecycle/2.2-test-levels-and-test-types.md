## Summary (ours)

Test levels are groups of activities organised together for a given stage of development. Test types group activities by quality characteristic and can be used at any level.

## Sections

- [2.2.1 Test Levels](2.2.1-test-levels.md): The five levels: component, component integration, system, system integration and acceptance.
- [2.2.2 Test Types](2.2.2-test-types.md): The four types: functional, non-functional, black-box and white-box.
- [2.2.3 Confirmation Testing and Regression Testing](2.2.3-confirmation-testing-and-regression-testing.md): Confirmation testing (is the defect fixed?) vs regression testing (did the change break something?).
