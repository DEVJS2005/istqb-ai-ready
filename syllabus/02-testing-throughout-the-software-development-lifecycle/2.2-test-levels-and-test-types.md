# 2.2. Test Levels and Test Types

> **Casca.** Este arquivo não contém o texto do syllabus. O resumo é nosso (não é texto do ISTQB).
> Para o conteúdo exato, veja a seção e a página indicadas no PDF oficial ou o arquivo em `syllabus-texto/`.

## Resumo (nosso)

Níveis de teste são grupos de atividades organizados juntos, em cada fase de desenvolvimento. Tipos de teste agrupam atividades por característica de qualidade e podem ocorrer em qualquer nível.

## Seções

- [2.2.1 Test Levels](2.2.1-test-levels.md): Os cinco níveis: componente, integração de componentes, sistema, integração de sistemas e aceite.
- [2.2.2 Test Types](2.2.2-test-types.md): Os quatro tipos: funcional, não funcional, caixa-preta e caixa-branca.
- [2.2.3 Confirmation Testing and Regression Testing](2.2.3-confirmation-testing-and-regression-testing.md): Teste de confirmação (o defeito foi corrigido?) vs teste de regressão (a mudança quebrou algo?).
