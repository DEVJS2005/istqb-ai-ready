# 2. Testing Throughout the Software Development Lifecycle

## Resumo (nosso)

Mostra como o teste se adapta ao modelo de desenvolvimento, as abordagens que usam testes para guiar o desenvolvimento (TDD, ATDD, BDD), DevOps, shift left e retrospectivas. Define os cinco níveis e os quatro tipos de teste, diferencia confirmação de regressão e trata do teste de manutenção.
