# 2.1.4. DevOps and Testing

> **Shell.** This file does not contain the syllabus text. The summary is ours (not ISTQB text).

## Summary (ours)

DevOps brings development and operations together with CI/CD and a delivery pipeline. Benefits: fast feedback, shift left, stable environments, visibility of non-functional qualities and less manual regression. Risks: setting up the pipeline, maintaining tools and paying for automation. Manual testing from the user's view is still needed.
