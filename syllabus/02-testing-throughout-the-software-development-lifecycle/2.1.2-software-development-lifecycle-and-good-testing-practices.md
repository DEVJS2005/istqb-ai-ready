# 2.1.2. Software Development Lifecycle and Good Testing Practices

## Resumo (nosso)

Toda atividade de desenvolvimento tem uma atividade de teste correspondente; cada nível de teste tem objetivos próprios; a análise e o projeto de teste começam na fase de desenvolvimento correspondente; e os testadores revisam rascunhos assim que existem.
