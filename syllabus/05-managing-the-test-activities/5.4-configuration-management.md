# 5.4. Configuration Management

> **Shell.** This file does not contain the syllabus text. The summary is ours (not ISTQB text).
> For the exact content, see the section and page given below in the official PDF, or the file in `syllabus-text/`.

## Summary (ours)

Identifies, versions and tracks test configuration items (plans, cases, scripts, results, environments). Approved items become a baseline and change only through formal change control, which makes earlier results reproducible. In DevOps, configuration management is usually automated in the pipeline.
