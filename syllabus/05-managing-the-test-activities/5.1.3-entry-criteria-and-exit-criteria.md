# 5.1.3. Entry Criteria and Exit Criteria

> **Shell.** This file does not contain the syllabus text. The summary is ours (not ISTQB text).
> For the exact content, see the section and page given below in the official PDF, or the file in `syllabus-text/`.

## Summary (ours)

Entry criteria are the preconditions to start an activity (resources, testware, initial quality). Exit criteria say when it is done (thoroughness measures such as coverage and open defects, plus yes/no checks). Running out of time or budget can end testing if the risk is accepted. In agile they become DoR and DoD.
