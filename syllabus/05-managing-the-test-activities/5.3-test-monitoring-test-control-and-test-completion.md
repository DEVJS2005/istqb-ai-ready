# 5.3. Test Monitoring, Test Control and Test Completion

## Summary (ours)

Monitoring gathers information on progress and exit criteria. Control issues corrective directives (reprioritise, re-check criteria, adjust the schedule, add resources). Completion consolidates experience and testware at project milestones.
