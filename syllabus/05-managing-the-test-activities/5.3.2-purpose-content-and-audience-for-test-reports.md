# 5.3.2. Purpose, Content and Audience for Test Reports

> **Shell.** This file does not contain the syllabus text. The summary is ours (not ISTQB text).
> For the exact content, see the section and page given below in the official PDF, or the file in `syllabus-text/`.

## Summary (ours)

The progress report is periodic and supports control: period, progress, impediments, metrics, risks and next period. The completion report comes at the end of a level, cycle or project: summary, evaluation against the plan, deviations, unmitigated risks, open defects and lessons learned. The audience sets the formality and frequency.
