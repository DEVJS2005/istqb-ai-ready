# 6.2. Benefits and Risks of Test Automation

> **Shell.** This file does not contain the syllabus text. The summary is ours (not ISTQB text).
> For the exact content, see the section and page given below in the official PDF, or the file in `syllabus-text/`.

## Summary (ours)

Benefits: less repetitive work, consistency, objective assessment, better information for management, faster feedback and more time for better tests. Risks: unrealistic expectations, wrong estimates, automating what should stay manual, over-reliance on the tool or vendor, abandoned open-source projects, platform incompatibility and regulatory non-compliance.
