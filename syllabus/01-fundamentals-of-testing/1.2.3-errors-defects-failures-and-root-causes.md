# 1.2.3. Errors, Defects, Failures, and Root Causes

> **Shell.** This file does not contain the syllabus text. The summary is ours (not ISTQB text).

## Summary (ours)

People make errors, which introduce defects, which may lead to failures when executed. Failures can also come from the environment. A root cause is the underlying reason for a problem; root cause analysis finds it so similar problems can be prevented.
