# 1.1.2. Testing and Debugging

> **Shell.** This file does not contain the syllabus text. The summary is ours (not ISTQB text).

## Summary (ours)

Testing exposes failures (dynamic) or defects (static); debugging locates the cause and removes it. A fix is followed by confirmation testing and, when needed, regression testing. Defects found statically need no reproduction or diagnosis.
