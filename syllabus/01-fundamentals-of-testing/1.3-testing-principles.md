# 1.3. Testing Principles

> **Shell.** This file does not contain the syllabus text. The summary is ours (not ISTQB text).
> For the exact content, see the section and page given below in the official PDF, or the file in `syllabus-text/`.

## Summary (ours)

Testing reveals defects but cannot prove their absence; exhaustive testing is not feasible; testing early saves money; defects tend to cluster; repeated tests lose power; testing depends on context; and the absence-of-defects fallacy (verification alone is not enough, validation is needed too).
